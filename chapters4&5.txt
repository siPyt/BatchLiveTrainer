Slides 4-21, 4-22, & 4-23 (Syntax — PDF Pages 73–75):
The master cheat sheet for DeltaV expression symbols:   / = Internal parameter at the current level.   ^/ = Internal parameter up one block level (e.g., ' ^/REQUEST.CV ' or ' ^/R_FILL_LEVEL.CV '—reaching up from RUN_LOGIC to the FILL Phase level).   // = External parameter outside this phase/module (e.g., '//XV_102/DC1/SP_D').   #...# = Encloses a Unit Alias (always preceded by //, like '//#BLEND_LEV_CV#'). (Exception: checking if an alias is ignored uses '/aliasname.IGN'.)   : = Separates a Named Set from its state name ('vlvnc-sp:OPEN').   := = Assignment operator used in Step Actions ('^/REQUEST.CV' := 3202;). Every action statement ends with a semicolon ;.   =, >, <, >=, <=, != = Comparison operators used in Transitions ('^/REQUEST.CV' = 0—no colon, no semicolon). Transition 1 (OUTLET_CLOSED):Condition c: '//#OUTLET_VLV#/PV.CV' = 'vlvnc-pv:CLOSED' (Wait until outlet valve is confirmed closed).   Step 2 (OPEN_INLET):Action d: '//#INLET_VLV#/MODE.TARGET' := CAS; (Put inlet valve in Cascade).   Action e: '//#INLET_VLV#/CAS_SP.CV' := 'vlvnc-sp:OPEN'; (Open inlet valve).   Transition 2 (LEVEL_MET):Condition f: '//#TANK_LEVEL#' >= '^/R_FILL_LEVEL.CV' (Wait until tank level reaches recipe target). Step 4 (COMPLETE):Action j: '^/RPT_FNL_LVL.CV' := '//#TANK_LEVEL#'; (Record final tank level into the Report parameter).   Action k: '//#INLET_VLV#/MODE.TARGET' := AUTO; (Release inlet valve back to Operator Auto mode).   Action l: '//#OUTLET_VLV#/MODE.TARGET' := AUTO; (Release outlet valve back to Operator Auto mode). Part 5: Workshop 2 — Adding HOLD_LOGIC & RESTART_LOGIC (Slides 4-53 to 4-63)Slide 4-53 (Phase Logic State Diagram — PDF Page 105):
Look at the state machine path when something goes wrong or an operator clicks Hold while FILL is Running:   Running $\xrightarrow{\text{Fail / Hold}}$ Holding (executes HOLD_LOGIC SFC) $\xrightarrow{\text{Sequence Done}}$ Held (sits safely paused).   When the operator clicks Restart: Held $\xrightarrow{\text{Restart \& not fail}}$ Restarting (executes RESTART_LOGIC SFC) $\xrightarrow{\text{Sequence Done}}$ returns to Running!   Slide 4-54 (PDF Page 106): (Blank spacer page.)   Slides 4-55 & 4-56 (Workshop - Hold — PDF Pages 107–108):What should a Color Tank do if the operator hits Hold while it is filling? Stop the flow immediately by closing the inlet valve!   You drill down into HOLD_LOGIC and add one step (CLOSE_INLET) and one termination (HOLD):   Step CLOSE_INLET: Drive INLET_VLV/MODE.TARGET := CAS; and INLET_VLV/CAS_SP.CV := 'vlvnc-sp:CLOSE';.   Termination HOLD: Wait for '//#INLET_VLV#/PV.CV' = 'vlvnc-pv:CLOSED'.   The moment the valve confirms closed, HOLD_LOGIC finishes (Sequence Done) and the phase sits safely in the Held state.   Slide 4-57 (Workshop - Restart — PDF Page 109):What should happen when the operator hits Restart from the Held state? Re-open the inlet valve so filling can resume! Termination RESTART: Wait for '//#INLET_VLV#/PV.CV' = 'vlvnc-pv:OPEN'.   Once the valve is open, RESTART_LOGIC finishes and jumps right back into RUN_LOGIC where it left off—waiting for TANK_LEVEL >= R_FILL_LEVEL!   Look at the huge time-saver on Step 3 of Slide 4-57: Because we added HOLD_LOGIC and RESTART_LOGIC to the FILL Phase Class in the library, it automatically propagated to UM_COLOR_100, 200, and 300 without us having to write it three times!
