Engine (src/renderer/src/engine):
- emStore.ts: Equipment Module Class categories and classes. The New dialog offers all seven algorithm types
  (Function Block Diagram, SFC, Command driven, State driven, Phase Algorithm, Phase with command-driven / state-
  driven run logic); Command driven and State driven are modeled, the rest explain they are not. A command-driven
  named set must contain the 255 (Idle) entry.
  * Command driven: one COMMAND_0000n SFC per named-set command (value 1..n), maximum time, enabled.
  * State driven: Items (name, Sequence, write path, readback path - module level parameters only) and one column per
    named-set state (Cascade/Auto/Manual/OOS, CLOSE/OPEN or the valve set). State Parameters per state: ENABLED,
    CFM_MAX_TIME, CFM_MIN_TIME (EmClass.stateParams; a state with ENABLED = False refuses A_COMMAND, like a disabled
    command). Sequence and CFM times are stored and shown only; all items of a state are still driven together.
  * Module blocks inside an EM class from the Control Module Classes 2STAGE_VALVE, NC_VALVE (NC_Valves), AGIT_MTR,
    OUT_PMP (2StateMotor). Block name = class name cut to 11 characters + _1 (2STAGE_VALV_1, NC_VALVE_1).
  * Runtime: A_COMMAND, A_TARGET, A_PV (Idle 255 while a command runs, then the command name), A_STATE, A_TIME,
    A_ABT_ON_NEW_CMD (False = finish the running command first, True = abort it), block status Running/Complete/

5A. CHAPTER 6 - AGITATE Unit Phase (pp 6-1 .. 6-54)
---------------------------------------------------
Status: workshop capabilities implemented and tested (2026-10-26). This adds tools, not a prebuilt AGITATE
class in the student's database. Complete Chapter 5's BLENDERS/UM_BL_500/UM_BL_600 configuration first.

- Phase actions: Pulse time/condition delays, Confirm expression and timeout, per-step TIME, PENDING_CONFIRMS,
  FAILED_CONFIRMS and CONFIRM_FAIL. Non-Boolean actions activate linked composites (name the action BLEND_TIMER;
  qualifier N activates the timer composite while that step is active).
- STEP_INDEX is now a writable phase parameter rather than the currently selected SFC step number. FAIL_INDEX is
  numeric for new runtimes and failures; nonzero failures enter Holding from Running/Restarting. Evaluation errors
  use index 255 with their diagnostic text. Legacy saved 'OK' values remain compatible.
- Control Studio on the phase class (the same ribbon, hierarchy, parameters and palette panes as DeltaV):
  * Hierarchy: right-click the right side of the Hierarchy window > Add Composite Block links a named block to
    TIMER_SEC (BLEND_TIMER). Selecting a block shows START/RESET/TIME_DURATION/ELAPSED_TIME in the Parameters pane;
    Hold stops START without losing elapsed time.
  * FAIL_MONITOR is a real function block diagram: drag CND, BFI and CALC from the "Calculation/Logic" palette,
    double-click for Properties (name, expression with the expression editor, DISABLE default), drag from an
    output pin (OUT_D, FIRST_OUT, OUT_INT, OUT1) to an input pin (IN_D1..IN_D16, IN1) to wire, select a wire and
    press Delete (or right-click) to remove it. Blocks can be moved; positions are saved. On-Line the pins show live
    values, wires turn green when TRUE and double-clicking a parameter in the Parameters pane writes it (enable
    conditions, BFI RESET_IN). FAIL_MONITOR executes conditions, the binary FIRST_OUT BFI and calculations while
    the phase is active, not Idle.
  * Hold/Restart/Stop/Abort sequences support alternate branches drawn as in DeltaV: select a step and use
    Insert > Branch (or the palette Branch item, or right-click > Add Alternate Branch); double-click a transition
    for its name, expression and Connect To step (or Termination); right-click > Add Sequence After extends a leg;
    palette Termination ends the selected leg; a step takes its first TRUE transition. Legs rejoin, loop back or end.
- CALC supports IF/THEN/ELSE/ENDIF and the conditional operator plus LOG2 for binary failure-index conversion.
  References include /+/phase parameters, local step/block paths, cross-composite paths and nested EM child paths.
  RESTART_TYPE uses $phase_restart_types Continue/From_Start; STEP_INDEX remains intact during Hold/Restart.
- Built-in phase_failures and $phase_restart_types are installed in fresh projects and added to older saves
  without replacing user configuration. Add failure messages 4-8 and download Changed Setup Data to BOTH the
  controller and workstation. Runtime named states and displayed failure messages use their deployed setup data.
- Clear Failures is available in the phase command selector. Failed phases cannot Restart until cleared.
  The Process picture, phase faceplate and On-Line system parameters show the failure and diagnostic.
  Blender tanks now open their unit faceplates from Process, just like the color tanks.
- Course 7016 Workshops -> Ch 6: configuration/timed operation, Hold/Restart, failure monitoring/recovery, and
  optional Stop/Abort/held-agitation exercises. The principal checklists have live checks; optional checks are manual.

Deliberate simplifications:
- RESET_IN on the BFI is written by logic (not wired); BFI inputs wire from block outputs only.
- Only the Chapter 6 TIMER_SEC linked template is modeled here, not an arbitrary composite-template editor.
- These are educational simulator capabilities, not vendor-controller certification.
