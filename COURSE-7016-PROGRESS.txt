-----------------
- Chapter 1 work was removed from the BatchLive GitHub repository (main reset to 0203c8f) and moved to the new

  * Save DV_School now - immediate save (it is also autosaved).

  The simulator engine code is shared with BatchLive and still covered by the engine test suite, but none of the

4. CHAPTER 4 - FILL Unit Phase (pp 4-1 .. 4-64)
-----------------------------------------------
Engine (src/renderer/src/engine):
- batchConfig.ts   classes, aliases, phase classes with batch input/report, algorithm and message parameters,
                   six composites (ABORT_LOGIC, FAIL_MONITOR, HOLD_LOGIC, RESTART_LOGIC, RUN_LOGIC, STOP_LOGIC),
                   sequences (steps/transitions/actions with N/P/S/R/D/L qualifiers), S88.01 state machine:
                   Idle -Start-> Running -done-> Complete -Reset-> Idle; Hold -> Holding -> Held -Restart->
                   Restarting -> Running (resumes RUN_LOGIC where it was); Stop -> Stopping -> Stopped;
                   Abort -> Aborting -> Aborted; an evaluation failure sends the phase to Holding with FAIL_INDEX.
- phaseExpr.ts     DeltaV expression parser/evaluator: '/X.CV', '^/X.CV', '//MOD/PARAM', '//#ALIAS#/PARAM',
                   '/ALIAS.IGN', 'set:STATE', :=, =, <>, !=, <, >, <=, >=, AND, OR, NOT, + - * /, string
                   concatenation with "double quotes", SELSTR, LOGEVENT, ABS/MIN/MAX and ; statement ends.
- batchStore.ts    configuration store (categories, classes, process cells, unit modules, alias resolution,
                   contained modules, cell members such as TANKSIM, assignment, unit/unit-phase/controller download
                   with the Upload dialog rows) and runtime (load/unload, owner External/DeltaV Batch, commands,
                   online parameters, per-unit configured parameter values, cascade remote setpoints on the XV
                   valves, the phase scan every simulation step).
- classLibrary.ts  per-tank fill rates (Color 100 6 gal/s, Color 200 8 gal/s, Color 300 5 gal/s) so the overshoot
                   optional exercise has a different overshoot on each tank.

How to do the Chapter 4 workshops (Course 7016 Workshops display shows each step with a live check):
  Workshop - FILL Phase
    Task 1  Explorer -> Library -> Advanced Definitions -> Process Cell Classes -> General: right-click -> New
            Process Cell Class PRODUCTION; drag PRODUCTION onto ED_CENTER_BATCH, rename PAINT_PRODUCTION.
    Task 2  Unit Classes -> New Category ChargeTankUnits -> New Unit Class COLORTANKS -> New -> Alias INLET_VLV,
            OUTLET_VLV, TANK_LEVEL.
    Task 3  Phase Classes -> New Category TankClasses -> New Phase Class FILL; New -> Batch input/report parameter
            R_FILL_LEVEL (Operating, Real, Input, 0 / 250 / 500 gal) and RPT_FNL_LVL (type Report as a new
            category, Real, Report, gal).
    Task 4  Open FILL with Control Studio, double-click Running (RUN_LOGIC), Palette -> Sequence (3 steps),
            rename and fill in:
              INIT          '//#OUTLET_VLV#/MODE.TARGET' := CAS;  '//#OUTLET_VLV#/CAS_SP.CV' := 'vlvnc-sp:CLOSE';
              OUTLET_CLOSED '//#OUTLET_VLV#/PV.CV' = 'vlvnc-pv:CLOSED'
              OPEN_INLET    '//#INLET_VLV#/MODE.TARGET' := CAS;   '//#INLET_VLV#/CAS_SP.CV' := 'vlvnc-sp:OPEN';
              LEVEL_MET     '//#TANK_LEVEL#' >= '^/R_FILL_LEVEL.CV'
              CLOSE_INLET   '//#INLET_VLV#/MODE.TARGET' := CAS;   '//#INLET_VLV#/CAS_SP.CV' := 'vlvnc-sp:CLOSE';
              INLET_CLOSED  '//#INLET_VLV#/PV.CV' = 'vlvnc-pv:CLOSED'
              COMPLETE      '^/RPT_FNL_LVL.CV' := '//#TANK_LEVEL#';  '//#INLET_VLV#/MODE.TARGET' := AUTO;
                            '//#OUTLET_VLV#/MODE.TARGET' := AUTO;
              COMPLETE_2    TRUE
            Save; drag FILL onto COLORTANKS.
    Task 5  Drag COLORTANKS onto PAINT_PRODUCTION three times (UM_COLOR_100/200/300); resolve aliases
            XV-n01, XV-n02, LI-n04/AI1/PV.CV.
    Task 6  Drag XV-n01, XV-n02, LI-n04 onto UM_COLOR_n00.
    Task 7  Unit Properties -> Display -> Primary Control Display = Process; unit phase FILL -> Phase type
            Controller; drag TANKSIM onto PAINT_PRODUCTION; drag PAINT_PRODUCTION onto CTLR1; Download CTLR1.
    Task 8  Process -> click Color 100 -> Load a Phase ... -> FILL; BatchHelp -> change R_FILL_LEVEL; phase
            faceplate -> Phase Command ... -> Start; when Complete -> Reset -> Unload. Repeat for 200 and 300.
  Workshop - Hold & Restart: HOLD_LOGIC = CLOSE_INLET (CAS, 'vlvnc-sp:CLOSE') + HOLD ('vlvnc-pv:CLOSED');
    RESTART_LOGIC = OPEN_INLET (CAS, 'vlvnc-sp:OPEN') + RESTART ('vlvnc-pv:OPEN'); Save; Download -> Unit Phase.
  Workshop - Verify Functionality: Start, Hold (Held, XV closed), Restart (XV opens, Running, filling resumes);
    repeat on 200 and 300 (download them first).
  Optional exercises: STOP_LOGIC and ABORT_LOGIC (close both valves, wait CLOSED, return to AUTO), verify with
    Stop / Abort; overshoot compensation in LEVEL_MET, hard coded (... - 20) and/or per unit (phase parameter such as
    OVERSHOOT, configured differently on each UM_COLOR unit phase and downloaded).

Syntax reference (chapters_1_and_4 PDF section 4.3) is executed by tests: '/REQUEST.CV' := 3202;
'^/REQUEST.CV' = 3202, <>, !=, '/INLET_VLV.IGN', '//XV-102/DC1/SP_D', LOGEVENT("..." + value), etc.


5. CHAPTER 5 - Unit Classes, Equipment Module Classes and Control Module Classes (pp 5-1 .. 5-54)
-------------------------------------------------------------------------------------------------
Status: DONE - all six Chapter 5 workshops, including both optional exercises, can be performed and are checked live.

Engine (src/renderer/src/engine):
- emStore.ts: Equipment Module Class categories and classes. The New dialog offers all seven algorithm types
  (Function Block Diagram, SFC, Command driven, State driven, Phase Algorithm, Phase with command-driven / state-
  driven run logic); Command driven and State driven are modeled, the rest explain they are not. A command-driven
  named set must contain the 255 (Idle) entry.
  * Command driven: one COMMAND_0000n SFC per named-set command (value 1..n), maximum time, enabled.
  * State driven: Items (name, write path, readback path - module level parameters only) and one States column per
    named-set state (Cascade/Auto/Manual/OOS, CLOSE/OPEN or the valve set).
  * Module blocks inside an EM class from the Control Module Classes 2STAGE_VALVE, NC_VALVE (NC_Valves), AGIT_MTR,
    OUT_PMP (2StateMotor). Block name = class name cut to 11 characters + _1 (2STAGE_VALV_1, NC_VALVE_1).
  * Runtime: A_COMMAND, A_TARGET, A_PV (Idle 255 while a command runs, then the command name), A_STATE, A_TIME,
    A_ABT_ON_NEW_CMD (False = finish the running command first, True = abort it), block status Running/Complete/
    Failed/Aborted, event journal entries "COMMAND_0000n Complete; A_PV = ...", state-driven readback checking.
- batchStore.ts: unit class module blocks (Private / Shared, Allow variant), automatic aliases per block, unit
  module instantiation (AGITATOR1, COLOR_IN_VLV1, BLNDR_OUTLET1 ...), renaming of instances everywhere (aliases,
  assignments, unit blocks, EM children), deleting modules (refused while assigned: "Delete its assignment first"),
  Delete Assignment, module descriptions, two stage valve Close/Dribble/Bulk, unit module rename/delete carrying
  the EM instances and private modules along.
- libraryStore.ts / classLibrary.ts: course process with BASE 400 (2000 gal, starts at 1500), MTR-403, FIC-404 flow
  loop (150 GPM at 100 % OUT, idle low-flow alarms disabled), LI-401; color dumps (5 gal/s Bulk, 1/5 in Dribble),
  blender drains 8 gal/s, agitator run time; every transfer is measured (amount, time, average SP, end level).
- Named sets in DV_School: EM-vlvnc-2stage (Close 1, Dribble 2, Bulk 3, Auto Mode 4, Idle 255) and EM_Outlet_State
  (Closed - CAS 1, Draining Waste - CAS 2, Releasing Product - CAS 3, Auto Mode 4, Idle 255), plus vlvnc2stage-sp/pv.

Screens:

  Physical Network -> CTLR1 contents: right-click a module -> Delete Assignment.
